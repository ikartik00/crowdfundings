# 🚀 Simple Crowdfunding DApp

## 📌 Project Title
SimpleCrowdfunding - A Minimal Ethereum-Based Crowdfunding Smart Contract

## 📖 Project Description
SimpleCrowdfunding is a lightweight, gas-efficient smart contract that allows users to fund a project and enables the project owner to collect funds once a predefined goal is met after the campaign deadline.

## 🌍 Project Vision
To empower developers and creators to launch decentralized crowdfunding campaigns with minimal complexity and cost, while ensuring transparent and immutable handling of funds on the Ethereum blockchain.

## ✨ Key Features
- ⏳ **Deadline-Based Funding**: Accepts contributions only before a specified deadline.
- 🎯 **Funding Goal**: Funds are released only if the target goal is achieved.
- 👤 **Ownership Control**: Only the owner can withdraw funds after meeting criteria.
- 📈 **Transparent Contributions**: Tracks each contributor’s donation publicly on-chain.

## 🔮 Future Scope
- 💸 **Refund Mechanism**: Enable contributors to reclaim funds if the goal is not met.
- 🖼️ **Front-End DApp**: Build an intuitive web interface using React and Web3.js.
- 🧠 **Milestone-Based Withdrawals**: Allow partial withdrawals upon reaching project milestones.
- 📬 **Event Logging**: Add events for better tracking of deposits and withdrawals.
- 🌐 **Multi-Currency Support**: Extend support for stablecoins or ERC-20 tokens.
